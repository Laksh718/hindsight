# Hindsight

A chat agent with one tool, web search, and a dated memory.

It remembers what it told you and when, and it can check whether that is still true.

> Work in progress. Setup, architecture and design notes land here as they are built.

## Run it

```bash
npm install
cp .env.example .env   # add two free keys: Gemini and Tavily
npm run dev            # http://localhost:3000
```
